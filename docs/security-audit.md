# Portfolio Security Audit

## Scope

The Atlas Horizonte project was reviewed before preparing this public portfolio package. The published site was not modified.

## Deliberately excluded

- Complete HTML, CSS, and JavaScript source.
- Firebase deployment and administration files.
- Firebase state folders, deployment caches, and logs.
- Build and administrative scripts.
- Credentials, private keys, service-account files, environment files, and tokens.
- Local configuration and generated artifacts.

## Findings

The production project contains public-facing integration identifiers for analytics and advertising. They are not included in this documentation-only portfolio package because they are not needed for the showcase.

No credentials, private keys, passwords, bearer tokens, service-account files, or environment files are included in this repository.

## Publishing rule

Keep this repository limited to portfolio documentation and public interface screenshots. Never add production source, deployment configuration, private dashboards, or secret material.
